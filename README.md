## 🌟 Spielidee & Philosophie

In **Chemistry Mystery** betritt der Spieler ein mysteriöses, hochmodernes Wissenschaftslabor. Verschlossene Sicherheitsschleusen, unbekannte Stoffproben, unbalancierte chemische Reaktionen und experimentelle Detektivfälle stellen den Forscher vor immer neue Herausforderungen.

### 4 Anpassbare Schwierigkeitsgrade (jederzeit umschaltbar)
- 🟢 **Entdecker:** Für Kinder und Einsteiger ohne Vorwissen – anschauliche Vergleiche, direkte Hilfestellungen und spielerische Grundlagen.
- 🔵 **Anfänger:** Für Schüler der Mittelstufe – Formelverständnis, Atombau und erste Reaktionsgleichungen.
- 🟠 **Fortgeschritten:** Für Oberstufe und Kenner – Wertigkeiten, stöchiometrischer Ausgleich, Säure-Base-Konzepte.
- 🟣 **Chemieexperte:** Für Meister – komplexe Redox- und Adsorptionsprozesse, quantitative Analytik und anspruchsvolle Detektivmissionen.

### Lernen statt bloßem Raten
- **Bei richtiger Antwort:** Kurze wissenschaftliche Erklärung der Gesetzmäßigkeit und ein anschauliches Alltagsbeispiel.
- **Bei falscher Antwort:** Kein Beschämen! Verständliche Erklärung des typischen Denkfehlers, gezielter wissenschaftlicher Tipp und unbegrenzte Folgeversuche.
- **Stufenweiser Hinweis:** Bei wiederholtem Fehlversuch wird eine ausführliche Schritt-für-Schritt-Anleitung freigeschaltet.

## 🧩 Die 8 Rätselmechaniken

Das Spiel verzichtet bewusst auf monotone Multiple-Choice-Einbahnstraßen:

1. **Elemente zuordnen (`ElementMatch.tsx`):** Taktiles Zuordnen von chemischen Symbolen, lateinischen Ursprüngen und deutschen Elementnamen.
2. **Molekülbaukasten (`MoleculeBuilder.tsx`):** Virtuelles Hinzufügen und Entfernen von Atomen aus einem begrenzten Elementvorrat mit Prüfung der Atomzusammensetzung gegen das Zielmolekül.
3. **Labor entschlüsseln (`LabDoorCipher.tsx`):** Futuristisches Nummern-Terminal zum Errechnen von Ordnungszahlen, Massen und Valenzen für Sicherheitsschleusen.
4. **Reaktionsgleichungen ausgleichen (`EquationBalancer.tsx`):** Schrittweises Erhöhen von Koeffizienten mit Atomzähler auf Edukt- und Produktseite zur Veranschaulichung der Massenerhaltung.
5. **Unbekannte Stoffproben analysieren (`SubstanceAnalysis.tsx`):** Durchführung sicherer virtueller Vortests (Flammenfärbung, pH-Wert, Löslichkeit, Säurereaktion).
6. **Periodensystem-Challenge (`PeriodicTableQuiz.tsx`):** Schnelles Auffinden gesuchter Elemente anhand von Gruppen-, Perioden- und Schalenkriterien.
7. **Chemie-Detektiv (`MysteryDetective.tsx`):** Begutachtung von Tatort-/Laborberichten, Sammeln von Indizien und Formulieren wissenschaftlicher Hypothesen.
8. **Wahr oder Falsch (`TrueFalseLab.tsx`):** Richtigstellung weitverbreiteter Alltagsirrtümer mit tiefgehender wissenschaftlicher Richtigstellung.

## 🏆 Lernsystem, Album & Periodensystem

### Adaptives Spaced-Repetition System (`ReviewCenter.tsx`)
Falsch beantwortete Rätsel werden automatisch in einer Wiederholungs-Warteschlange gespeichert. Wird ein Rätsel im Wiederholungsmodus erneut gelöst, erhält der Spieler:
- **+15 XP Bonus**
- Das seltene Abzeichen **„Wissens-Wiederbelebung“**
- Permanente Vertiefung des Wissens

### Interaktiver Bohr-Atom-Visualizer (`AtomVisualizer.tsx`)
- Physikalisches Schalenmodell ($K, L, M, N, O, P, Q$) gerendert als gestochen scharfe Vektorgrafik (SVG).
- Animierte Elektronenorbits mit Schalenhervorhebung.
- Interaktiver Klick auf jede Schale zeigt Hauptquantenzahl $n$ und Elektronenanzahl.
- Speziell hervorgehobene Valenzelektronen zur Erklärung chemischer Bindungen.

### Periodensystem der Elemente (PSE-Modal)
- Jederzeit über den Header oder **direkt während eines Rätsels** mit 1 Klick aufrufbar.
- 118 vollständig erfasste Elemente mit Massen, Wertigkeiten, Alltagsbeispielen und Fun Facts.
- Filterbar nach Alkalimetallen, Erdalkalimetallen, Halogenen, Edelgasen, Übergangsmetallen etc.

### Holografisches Sammelalbum (`ElementCardAlbum.tsx`)
- Sammle Elementkarten in 3 Seltenheitsstufen (*Gewöhnlich, Selten, Legendär*).
- 11 freischaltbare Leistungs-Abzeichen für besondere Entdeckungen und Serien.

## 💻 Technische Architektur & 100% Offline-Design

- **Framework:** React 19 + TypeScript
- **Bundler:** Vite 6
- **Styling:** TailwindCSS v4 mit Glassmorphism- und Glow-Effekten
- **Icons:** Lucide React
- **Audio:** Reiner **Web Audio API Synthesizer** (`audio.ts`):
  - Synthetisiert Sinus-, Dreieck- und Rauschwellen mathematisch im Browser.
  - 0 KB Audio-Dateien, absolut keine Ladezeiten, funktioniert 100 % offline ohne Internetverbindung.
- **Speicherung:** `localStorage` mit nativer JSON-Export- und Importfunktion (Backups bleiben beim Nutzer).
- **Datenschutz:** 0 Tracker, 0 Cookies, keine externen APIs, DSGVO-konform.
- **Barrierefreiheit:** Automatische Erkennung von `prefers-reduced-motion` sowie manuelle Umschaltung für reduzierte Animationen.

## 📱 Android-Build & App-Verpackung (Capacitor & PWA)

Das Spiel ist für zwei moderne Auslieferungswege auf Android vorbereitet:

### Option A: Progressive Web App (PWA) – Direkt ohne Store
1. Öffne die Web-App im Chrome-Browser auf einem Android-Smartphone.
2. Tippe auf das Menü (drei Punkte) und wähle **„Zum Startbildschirm hinzufügen“** bzw. **„App installieren“**.
3. Die App startet nun im Vollbild-Modus (`standalone`), nutzt das hinterlegte Icon (`icon.svg`) und funktioniert dank vollständiger Offline-Architektur auch im Flugmodus.

---

### Option B: Native Android APK mit Capacitor

Dank der vorbereiteten Konfigurationsdatei `capacitor.config.ts` lässt sich das Webprojekt mit wenigen Befehlen in eine native Android-App umwandeln:

#### 1. Voraussetzungen
- Node.js (ab Version 18)
- Android Studio mit Android SDK (API-Level 34 empfohlen)

#### 2. Capacitor-Pakete installieren
Öffne ein Terminal im Projektverzeichnis `C:\Users\Abdal\Desktop\AITarek\chemi`:
```bash
npm install @capacitor/core @capacitor/cli @capacitor/android
```

#### 3. Android-Plattform initialisieren
```bash
npx cap add android
```
*Dadurch wird der native Android-Projektordner `android/` mit allen Gradle-Dateien generiert.*

#### 4. Web-Build erstellen und synchronisieren
```bash
npm run cap:build
```
*(Dies führt `tsc -b && vite build` aus und kopiert alle Web-Assets automatisch in das Android-Projekt).*

#### 5. Projekt in Android Studio öffnen & APK bauen
```bash
npm run cap:android
```
1. Android Studio öffnet das Projekt.
2. Wähle im oberen Menü: **Build > Build Bundle(s) / APK(s) > Build APK(s)**.
3. Die fertige `.apk`-Datei befindet sich anschließend unter:  
   `android/app/build/outputs/apk/debug/app-debug.apk`
4. Diese APK kann direkt auf jedes Android-Smartphone übertragen oder über den Google Play Store veröffentlicht werden!
